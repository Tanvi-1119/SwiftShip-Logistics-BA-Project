# SwiftShip Logistics — Business Analyst Project

## Project Overview
This project demonstrates a real-world Business Analyst workflow for SwiftShip Logistics, 
a fictional logistics company facing challenges with their return order management process. 
The goal is to analyze the problem, gather requirements, and propose a structured solution 
using industry-standard BA documentation.

## Business Problem
SwiftShip Logistics is experiencing three core operational problems:
- Non-standardized manual data entry across different client types
- Unstable web platform causing workflow interruptions
- Manual confirmation emails leading to delays and missed urgent requests
